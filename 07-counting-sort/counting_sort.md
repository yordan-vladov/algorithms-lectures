## Мотивация

- Всички алгоритми досега (Bubble, Selection, Insertion, Quick, Merge) сравняват елементи
- Доказано е, че **сравнителните** алгоритми не могат да са по-бързи от **O(n log n)**
- Но ако знаем нещо повече за данните - напр. че са **малки цели числа** - можем да сортираме **без сравнения**, за O(n)

---

## Какво е Counting Sort?

- **Counting Sort** сортира, като **преброява** колко пъти се среща всяка стойност
- Не сравнява елементи един с друг - използва стойностите им директно като индекси
- Изисква да знаем **диапазона** на стойностите предварително (напр. цели числа от 0 до k)

---

## Принцип на работа - преброяване

```
arr = [4, 2, 2, 8, 3, 3, 1]

Преброяваме срещанията на всяка стойност (0..8):

стойност:  0  1  2  3  4  5  6  7  8
count:     0  1  2  2  1  0  0  0  1
```

- `count[v]` = колко пъти стойността `v` се среща в `arr`

---

## Принцип на работа - префиксни суми

- Преобразуваме `count` в **префиксни суми**
- `count[v]` вече означава: "колко елемента са `<= v`" = последната позиция на `v` в изхода

```
преди:     0  1  2  2  1  0  0  0  1
след:      0  1  3  5  6  6  6  6  7
           ↑              value=4 → последните 6 позиции
        value=0 → 0 елемента <= 0
```

---

## Принцип на работа - построяване на изхода

- Обхождаме `arr` **отзад напред** (за стабилност) и поставяме всеки елемент на позицията `count[value] - 1`

```
arr = [4, 2, 2, 8, 3, 3, 1]           count (префиксни суми): [0,1,3,5,6,6,6,6,7]

i=6: arr[6]=1 → count[1]=1 → output[0]=1, count[1]=0
i=5: arr[5]=3 → count[3]=5 → output[4]=3, count[3]=4
i=4: arr[4]=3 → count[3]=4 → output[3]=3, count[3]=3
i=3: arr[3]=8 → count[8]=7 → output[6]=8, count[8]=6
...
```

---

## Псевдокод

```
намери maxVal в arr

count = масив от нули с размер maxVal + 1
за всяко x в arr:
    count[x]++

// префиксни суми
за i от 1 до maxVal:
    count[i] += count[i - 1]

// построяваме изхода отзад напред за стабилност
output = масив със същия размер като arr
за i от последния индекс на arr до 0:
    count[arr[i]]--
    output[count[arr[i]]] = arr[i]
```

## Примерна имплементация на C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void countingSort(vector<int>& arr) {
    if (arr.empty()) return;

    int maxVal = *max_element(arr.begin(), arr.end());

    // count[v] = колко пъти се среща стойността v
    vector<int> count(maxVal + 1, 0);
    for (int x : arr) count[x]++;

    // префиксни суми - count[v] става "последна позиция на v в изхода"
    for (int i = 1; i <= maxVal; i++) {
        count[i] += count[i - 1];
    }
```

---

## Примерна имплементация - построяване на изхода

```cpp
    // строим изходния масив, обхождайки arr отзад напред за стабилност
    vector<int> output(arr.size());
    for (int i = (int)arr.size() - 1; i >= 0; i--) {
        output[--count[arr[i]]] = arr[i];
    }

    arr = output;
}
```

*(пълният код е във `counting_sort.cpp`)*

---

## Защо обхождаме отзад напред?

- Ако обхождаме отпред назад - алгоритъмът пак сортира правилно, но **не е стабилен**
- Обхождайки отзад напред - последният елемент с дадена стойност се поставя последен сред "равните" - запазва се относителният ред от входа

```
arr = [3a, 1, 3b]   (3a и 3b - две тройки, различни само по етикет)

Отзад напред: 3b се обработва първо → отива на по-задна позиция
              3a се обработва после → отива на по-предна позиция
Резултат: [1, 3a, 3b]   ← редът им от входа е запазен
```

## Пример за употреба

```cpp
int main() {
    vector<int> arr = {4, 2, 2, 8, 3, 3, 1};

    countingSort(arr);

    for (int x : arr) cout << x << " ";
    // Изход: 1 2 2 3 3 4 8
}
```

## Сложност във времето

| Стъпка                  | Сложност |
| ------------------------ | -------- |
| Намиране на maxVal       | O(n)     |
| Преброяване              | O(n)     |
| Префиксни суми           | O(k)     |
| Построяване на изхода    | O(n)     |
| **Общо**                 | **O(n + k)** |

- `n` = брой елементи, `k` = диапазон на стойностите (maxVal)
- Ако `k = O(n)` → алгоритъмът е **линеен**, O(n) - по-бърз от всеки сравнителен алгоритъм!

---

## Сложност по памет

- Нужни са два допълнителни масива: `count` (размер `k`) и `output` (размер `n`)
- Памет: **O(n + k)**
- За разлика от Quick Sort/Merge Sort - **не** е in-place

---

## Предимства на Counting Sort

- **Линейна сложност** O(n + k) - по-бърз от всеки сравнителен алгоритъм, когато `k` не е много по-голямо от `n`
- **Стабилен** - при правилна имплементация (обхождане отзад напред)
- Прост принцип - директно броене

---

## Недостатъци на Counting Sort

- Работи само за **цели числа** (или данни, преобразими до малък диапазон от цели числа)
- Изисква да знаем **диапазона** `k` предварително
- Неефективен при **голям диапазон** спрямо броя елементи - напр. `k = 10^9`, `n = 100` → безсмислено много памет
- Не е сравнителен алгоритъм - не работи за произволни обекти без числов ключ

---

## Counting Sort срещу сравнителните алгоритми

| Характеристика       | Counting Sort            | Quick Sort / Merge Sort |
| ---------------------- | --------------------------- | -------------------------- |
| Сложност              | O(n + k)                    | O(n log n)                 |
| Тип                    | Не сравнява елементи         | Сравнява елементи           |
| Приложимост            | Само цели числа с малък диапазон | Всякакви сравними данни |
| Памет                  | O(n + k)                    | O(log n) - O(n)             |

---

## Кога да използваме Counting Sort?

- Когато сортираме **цели числа** с известен и **сравнително малък диапазон** (`k = O(n)`)
- Примери: оценки от 0 до 100, възраст на хора, брой срещания на думи с индекси
- Използва се и като **стъпка** в Radix Sort - сортиране на числа по цифри

## Обобщение

- Counting Sort сортира чрез **преброяване на срещанията**, без сравнения между елементи
- Сложност **O(n + k)** - линейна, когато диапазонът `k` е сравним с `n`
- Стабилен, но изисква допълнителна памет и работи само за цели числа с известен диапазон
- Пробива границата O(n log n) на сравнителните алгоритми, като използва допълнителна информация за данните
