# Увод в Алгоритми и Структури от Данни

Материали за курса по **Увод в Алгоритми и Структури от Данни**: лекции, обяснения и примерен код (основно C++), организирани по теми в отделни папки.

Всяка папка съдържа `.md` файл с теорията по темата, а част от тях включват и файлове с изходен код, илюстриращи разглежданите алгоритми и структури от данни.

- Всяка тема е в собствена папка, номерирана по реда на изучаване (`NN-tema`).
