## Python срещу C++

| Python                        | C++                                         |
| ----------------------------- | ------------------------------------------- |
| Интерпретиран, изпълнява се ред по ред | **Компилиран** до машинен код преди изпълнение |
| Динамично типизиран           | **Статично** типизиран - типът е фиксиран при декларацията |
| Блокове чрез **отстъп**       | Блокове чрез **`{ }`**                      |
| Край на израз - нов ред       | Край на израз - **`;`**                     |
| Автоматично управление на паметта | Ръчно управление при указателите (`new`/`delete`) |
| Бавен, лесен за писане        | **Бърз**, по-многословен                    |

- Затова C++ се ползва при състезания и задачи, където скоростта е важна

## Компилация и стартиране

```
g++ -std=c++17 -o program program.cpp     # компилира program.cpp до изпълним файл
./program                                  # стартира го
```

- Ако има **синтактична грешка** или грешен тип, програмата **изобщо не се компилира**
- В Python същата грешка би се проявила чак при изпълнение на реда
- `-std=c++17` - версията на езика (нужна за някои по-нови възможности като `auto [a, b]`)

## Първата програма

```python
# Python
print("Hello, world!")
```

```cpp
// C++
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world!" << endl;
    return 0;
}
```

- `#include <iostream>` - като `import`; включва библиотеката за вход/изход
- `using namespace std;` - за да пишем `cout` вместо `std::cout`
- `int main()` - **входната точка**; програмата започва оттук
- `return 0;` - "приключих успешно"
- Коментари: `//` за един ред, `/* ... */` за няколко (в Python - `#`)

## Вход и изход

```cpp
int a, b;
cin >> a >> b;                          // Python: a, b = map(int, input().split())
cout << "Сума: " << a + b << endl;      // Python: print("Сума:", a + b)
```

- `cout << ...` - изход; `<<` "излива" стойности в потока и може да се верижи
- `cin >> ...` - вход; `>>` чете стойност **според типа** на променливата
- `endl` - нов ред (`"\n"` върши същата работа и е малко по-бързо)
- Няма автоматичен интервал между стойностите като в `print` - слагаме го ръчно:

```cpp
cout << x << " " << y << endl;
```

## Основни типове

| Тип         | Какво съдържа                  | Пример              | Python аналог |
| ----------- | ------------------------------ | ------------------- | ------------- |
| `int`       | цяло число (~ ±2·10⁹)          | `int a = 7;`        | `int`         |
| `long long` | голямо цяло (~ ±9·10¹⁸)        | `long long b = 1e10;` | `int`       |
| `double`    | число с плаваща запетая        | `double pi = 3.14;` | `float`       |
| `bool`      | `true` / `false`               | `bool ok = true;`   | `bool`        |
| `char`      | **един** символ                | `char c = 'A';`     | `str` (дължина 1) |
| `string`    | текст                          | `string s = "hi";`  | `str`         |

- Типът се пише **преди** името: `int x = 5;`
- Не може да смените типа на променлива по-късно: `x = "text"` е грешка
- `'A'` (единични кавички) - символ, `"A"` (двойни) - низ. Не са едно и също!

## Променливи и константи

```cpp
int a = 7;
int b;                    // ВНИМАНИЕ: b има "боклук", не 0 (в Python няма такова нещо)
const int MAX_N = 100;    // константа - опит за промяна е грешка при компилация
auto x = 2.5;             // компилаторът извежда типа сам (double)
```

- Локалните променливи **не се инициализират** сами - винаги им давайте начална стойност
- `auto` е удобно при дълги типове: `auto it = v.begin();`
- Все пак типът си остава фиксиран - `auto` не прави езика динамичен

## Числата в C++ - три важни разлики

```cpp
cout << 7 / 2;          // 3    (цяло / цяло = цяло, дробната част се отрязва)
cout << 7 / 2.0;        // 3.5  (ако единият е double, резултатът е double)
cout << -7 / 2;         // -3   (отрязва към нулата; в Python -7 // 2 = -4)
cout << 7 % 3;          // 1
```

1. **Целочислено деление** - `/` върху два `int` дава `int`
2. **Няма `**`** и няма `//` - за степен се ползва `pow()` или цикъл
3. **Препълване** - `int` не расте безкрайно като в Python. Над `INT_MAX` (2 147 483 647) резултатът е **неправилен**; за големи числа ползваме `long long`

```cpp
#include <climits>
int inf = INT_MAX;      // често се ползва за "безкрайност" в алгоритмите
```

## Символите са числа

```cpp
char c = 'A';
cout << c + 1;              // 66   ('A' е 65)
cout << (char)(c + 1);      // B    (преобразуване на типа)
cout << '7' - '0';          // 7    (така превръщаме цифра-символ в число)
```

- `(char)x`, `(int)x`, `(double)x` - **явно преобразуване** (cast)
- Използва се често при Counting Sort и задачи със символи

## Оператори

| Python            | C++                  |
| ----------------- | -------------------- |
| `and`, `or`, `not` | `&&`, `\|\|`, `!`   |
| `x += 1`          | `x += 1` или `x++`   |
| `a if c else b`   | `c ? a : b`          |
| `a == b`, `a != b` | `a == b`, `a != b`  |
| `a, b = b, a`     | `swap(a, b)`         |
| `min(a, b)`       | `min(a, b)`          |

- `x++` увеличава с 1 (`x--` - намалява) - няма го в Python
- `=` е присвояване, `==` е сравнение - `if (x = 5)` се компилира, но е **грешка в логиката**

## Условия

```python
# Python
if x > 0:
    print("положително")
elif x == 0:
    print("нула")
else:
    print("отрицателно")
```

```cpp
// C++
if (x > 0) {
    cout << "положително" << endl;
} else if (x == 0) {
    cout << "нула" << endl;
} else {
    cout << "отрицателно" << endl;
}
```

- Условието е **винаги в скоби**; вместо `elif` - `else if`
- Ако тялото е един израз, `{ }` могат да се пропуснат (`if (x > 0) cnt++;`)
- Тернарен оператор: `cout << (x > 0 ? "плюс" : "не плюс");`

## Цикли `for` и `while`

```python
# Python
for i in range(5):            print(i)
for i in range(10, 0, -3):    print(i)
while k > 0:                  k -= 1
```

```cpp
// C++
for (int i = 0; i < 5; i++) cout << i << " ";        // 0 1 2 3 4
for (int i = 10; i > 0; i -= 3) cout << i << " ";    // 10 7 4 1
while (k > 0) { k--; }
```

- `for (инициализация; условие; стъпка)` - три части, разделени с `;`
- Както в Python: `break` излиза от цикъла, `continue` прескача итерацията

## `do-while` и range-based `for`

```cpp
int k = 0;
do {
    cout << "поне веднъж" << endl;    // тялото се изпълнява ПОНЕ веднъж
} while (k > 0);

vector<int> v = {4, 8, 15};
for (int x : v) cout << x << " ";     // Python: for x in v
```

- `do { ... } while (условие);` - проверката е **след** тялото
- `for (int x : v)` - обхожда елементите; `x` е **копие**
- За промяна на елементите ползваме референция: `for (int& x : v) x *= 2;`

## Функции

```python
# Python
def add(a, b):
    return a + b
```

```cpp
// C++
int add(int a, int b) {
```

```cpp
int factorial(int n) {
    if (n <= 1) return 1;

}
```

## Предаване по стойност и по референция

```cpp
void by_value(int x) { x = 100; }     // променя КОПИЕ
void by_ref(int& x)  { x = 100; }     // & - променя ОРИГИНАЛА

int n = 1;
by_value(n);    // n е все още 1
by_ref(n);      // n вече е 100
```

- По подразбиране C++ **копира** аргумента - за разлика от Python, където се предава референция към обект
- `int&` - **референция**: друго име на същата променлива
- Така пишем функции, които **променят** аргумента си (напр. `swap`, сортиране на място)

## `const&` - без копиране

```cpp
int sum_all(const vector<int>& v) {     // не копира вектора и не може да го промени
    int total = 0;
    for (int x : v) total += x;
    return total;
}
```

- Копирането на голям `vector` е **бавно** - O(n) при всяко извикване
- `const T&` = "виждам оригинала, но не го пипам" - стандартен начин за подаване на големи обекти
- Ще виждате `vector<int>& arr` в сортиращите алгоритми - те променят масива **на място**

## Масиви

```cpp
int arr[5] = {5, 1, 4, 2, 8};      // фиксиран размер
int n = 5;                          // дължината трябва да се пази отделно!

for (int i = 0; i < n; i++) cout << arr[i] << " ";
```

- Размерът е фиксиран и **не може да се променя**
- Масивът **не знае дължината си** (няма `len(arr)`)
- **Няма проверка на границите** - `arr[10]` не дава грешка, а чете чужда памет (недефинирано поведение)
- Затова в практиката предпочитаме `vector`

```python
v = [5, 1, 4]
```

## `size()` и `size_t` - капан

```cpp
vector<int> v;                         // празен
for (int i = 0; i < v.size() - 1; i++) // ГРЕШКА!
```

- `v.size()` връща **неотрицателен** тип (`size_t`)
- `0 - 1` при неотрицателни числа не дава `-1`, а **огромно число** - цикълът тръгва да чете извън вектора
- Безопасно: `i + 1 < v.size()` или `int n = v.size();` и после ползваме `n - 1`
- В курса често пише `int n = arr.size();` - точно заради това

## Итератори и алгоритми от `<algorithm>`

```cpp
sort(v.begin(), v.end());              // Python: v.sort()
reverse(v.begin(), v.end());           // Python: v.reverse()
int mx = *max_element(v.begin(), v.end());   // Python: max(v)
```

- `v.begin()` и `v.end()` - **итератори**: позиция на първия елемент и **едно след последния**
- Алгоритмите работят върху диапазон `[begin, end)`
- Сортиране на част от вектора: `sort(v.begin() + 2, v.begin() + 5);`
- `*` пред итератор връща елемента, към който сочи (както при указателите)

## Указатели - идеята

- Всяка променлива живее на някакъв **адрес** в паметта
- **Указател** е променлива, която пази адрес

```cpp
int x = 42;
int* p = &x;          // &x - "адресът на x"; p сочи към x

cout << *p;           // 42   (*p - "стойността на адреса")
*p = 7;               // променя x през указателя
cout << x;            // 7
```

```
   x: [ 7 ]  ← адрес 0x1000
   p: [0x1000]  ── сочи към x
```

- `int*` - "указател към int"
- `&x` - вземи адрес; `*p` - следвай адреса

## `nullptr`

```cpp
int* p = nullptr;         // "не сочи към нищо" - като None
if (p == nullptr) { ... }
```

- Достъпът до стойността (`*p`) през `nullptr` **срива програмата**
- Проверяваме за `nullptr` преди да ползваме указателя
- В структури като свързан списък и дърво `nullptr` означава "края" - няма следващ възел

## Динамична памет: `new` и `delete`

```cpp
int* p = new int(99);        // заделя памет в "heap" и връща адреса ѝ
cout << *p;
delete p;                    // ОСВОБОЖДАВА паметта

int* arr = new int[3]{1, 2, 3};   // динамичен масив
delete[] arr;                     // за масиви - delete[]
```

- В Python `garbage collector` чисти автоматично; в C++ **ние** връщаме паметта
- Забравен `delete` = **изтичане на памет** (memory leak)
- Двоен `delete` или ползване след `delete` = **грешка**
- Тук `new` ползваме основно за възли на **свързан списък** и **дървета**

## `struct`

```python
# Python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
```

```cpp
// C++
struct Point {
    int x, y;
    Point(int x, int y) : x(x), y(y) {}        // конструктор
};

Point p(3, 4);
cout << p.x;              // достъп до поле с точка
```

- `struct` групира данни под едно име
- **Конструкторът** носи името на структурата и няма тип на резултата
- `: x(x), y(y)` - **списък за инициализация** - задава началните стойности на полетата
- `;` след затварящата `}` е **задължителна**

---

## Указател към `struct` - оператор `->`

```cpp
struct Node {
    int data;
    Node* next;
    Node(int value) : data(value), next(nullptr) {}
};

Node* head = new Node(1);
head->next = new Node(2);          // head->next е същото като (*head).next
cout << head->next->data;          // 2
```

- `.` - когато имаме **самия обект**; `->` - когато имаме **указател** към него
- `head->next->data` - "отиди към следващия и вземи данните"
- Това е основата на **свързаните списъци** и **дърветата**

---

## Обхождане на свързан списък

```python
# Python
cur = head
while cur is not None:
    print(cur.data)
    cur = cur.next
```

```cpp
// C++
for (Node* cur = head; cur != nullptr; cur = cur->next)
    cout << cur->data << " ";
```

```cpp
// освобождаване
while (head != nullptr) {
    Node* tmp = head;
    head = head->next;
    delete tmp;
}
```

- Запазваме `tmp`, преди да преместим `head`, иначе губим възела

## `class` и капсулация

```cpp
class Counter {
private:                       // достъпно само вътре в класа
    int count;
public:                        // достъпно отвсякъде
    Counter() : count(0) {}
    void increment() { count++; }
    int get() const { return count; }
    ~Counter() { /* почистване */ }    // деструктор
};

Counter c;
c.increment();
cout << c.get();      // 1
```

- `class` е като `struct`, но членовете са **private** по подразбиране
- `const` след метода - методът **не променя** обекта
- **Деструкторът** `~Име()` се вика автоматично при унищожаване - там правим `delete` за паметта
- Няма `self` - членовете се виждат директно; `this` е указател към текущия обект

## `pair`, `map` и `set`

```cpp
pair<int, string> pr = {1, "one"};
cout << pr.first << " " << pr.second;          // Python: pr[0], pr[1]

unordered_map<string, int> ages;               // Python: ages = {}
ages["Ana"] = 20;
if (ages.count("Ana") > 0) { ... }             // Python: "Ana" in ages

for (auto& [name, age] : ages)                 // Python: for k, v in ages.items()
    cout << name << ":" << age << endl;

set<int> st = {3, 1, 3, 2};                    // {1, 2, 3} - уникални, подредени
```

- `ages["X"]` за липсващ ключ **създава** запис със стойност 0 - не хвърля грешка като в Python
- `auto& [k, v]` - **структурирано свързване** (разопаковане на двойка)
- `map` и `set` са подредени (O(log n)); `unordered_*` са хеш-базирани (O(1) средно)

## `stack`, `queue`, `priority_queue`

```cpp
stack<int> stk;
stk.push(1); stk.push(2);
cout << stk.top();        // 2
stk.pop();                // премахва, но НЕ връща стойност

queue<int> q;
q.push(1); q.push(2);
cout << q.front();        // 1
q.pop();

priority_queue<int> maxh;                              // max-heap
priority_queue<int, vector<int>, greater<int>> minh;   // min-heap
```

- `pop()` **не връща** елемента - първо `top()` / `front()`, после `pop()`
- Празен контейнер + `top()`/`pop()` = недефинирано поведение → проверяваме `.empty()`
- `priority_queue` по подразбиране взима **най-големия** (за най-малък - `greater<int>`)
- Python `heapq` е min-heap - в C++ е обратното

## Ламбда изрази

```python
# Python
items.sort(key=lambda it: it.weight)
```

```cpp
// C++
sort(items.begin(), items.end(),
     [](const Item& a, const Item& b) { return a.weight < b.weight; });
```

- `[](параметри) { тяло }` - анонимна функция
- Компараторът връща `true`, ако `a` трябва да е **преди** `b`
- `[]` е "captures" - кои външни променливи виждаме; `[&]` - всички по референция
- Ползва се в `sort`, `priority_queue` и жадните алгоритми

## Чести грешки

- **Забравена `;`** - най-честата грешка при компилация; съобщението често сочи **следващия** ред
- **`=` вместо `==`** в условие
- **Излизане извън масив/вектор** - няма грешка, а "случайни" стойности или срив
- **Неинициализирана променлива** - съдържа боклук
- **`int` препълване** - при суми, произведения, факториели ползвайте `long long`
- **`size() - 1`** върху празен `vector`
- **`7 / 2`** дава `3`, не `3.5`
- **Забравен `break`** в `switch`
- **Забравен `delete`** или ползване на указател след `delete`

## Как да четем кода от курса

```cpp
void bubbleSort(vector<int>& arr) {
    int n = arr.size();

    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
            }
        }
    }
}
```

- `void` - функцията нищо не връща
- `vector<int>& arr` - вектор от цели числа, предаден по **референция** → сортира се **оригиналът**
- `int n = arr.size();` - пазим дължината в променлива
- Двата вложени `for` са като `for i in range(n - 1)` и `for j in range(n - 1 - i)`
- `swap` размества два елемента

## Още един пример - възел и списък

```cpp
struct Node {
    int data;
    Node* next;
    Node(int value) : data(value), next(nullptr) {}
};

void push_front(Node*& head, int value) {
    Node* new_node = new Node(value);
    new_node->next = head;
    head = new_node;
}
```

- `Node*&` - **референция към указател**: функцията може да смени накъде сочи `head`
- Чете се: "създай възел, закачи го пред стария `head`, направи го нов `head`"
- Всичко това вече го знаем: `struct`, конструктор, `new`, `->`, `nullptr`
