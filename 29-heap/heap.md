## Мотивация

- Трябва ни структура, от която многократно вадим **най-малкия** (или най-големия) елемент
- Несортиран масив → намиране на минимум е O(n) всеки път
- Сортиран масив → вмъкване на нов елемент е O(n)
- BST дава O(log n) за всичко, но е по-сложен и не е винаги балансиран

```
Проблем: обработвай задачи по приоритет (най-спешната първо)
  Несортиран масив → insert O(1), намери мин O(n)
  Сортиран масив   → insert O(n), намери мин O(1)
  Heap             → insert O(log n), намери мин O(1)  ← баланс
```

---

## Какво е heap?

- **Heap** е **пълно двоично дърво** (complete binary tree), което спазва **heap свойство**
- **Min-heap:** всеки родител ≤ децата си → коренът е **най-малкият** елемент
- **Max-heap:** всеки родител ≥ децата си → коренът е **най-големият** елемент

```
Min-heap:                Max-heap:
      [2]                     [9]
     /   \                   /   \
   [5]   [3]               [7]   [8]
   / \    /                / \    /
 [8] [7] [9]             [2] [5] [3]
```

- За разлика от BST, **няма** наредба между ляво и дясно поддърво - само родител ≤/≥ деца

---

## Пълно двоично дърво (complete binary tree)

- Всички нива са запълнени, освен евентуално последното
- Последното ниво се запълва **отляво надясно**, без празнини

```
Валидно (пълно):          Невалидно:
      [2]                      [2]
     /   \                    /   \
   [5]   [3]                [5]   [3]
   /                           \
 [8]                           [8]   ← празнина отляво!
```

- Благодарение на тази структура, heap може да се пази **компактно в масив**, без указатели

## Представяне на heap чрез масив

```
Heap (min-heap) като дърво:
          [2]
         /   \
       [5]   [3]
       / \    /
     [8] [7] [9]

Като масив:
 индекс: 0  1  2  3  4  5
 стойност: [2, 5, 3, 8, 7, 9]
```

За елемент на индекс `i`:
```
ляво дете  = 2*i + 1
дясно дете = 2*i + 2
родител    = (i - 1) / 2   (целочислено деление)
```

- Никакви указатели - само аритметика върху индекси!

---

## Проверка на формулите

```
индекс 1 (стойност 5): родител = (1-1)/2 = 0 → [2] ✓
индекс 3 (стойност 8): родител = (3-1)/2 = 1 → [5] ✓
индекс 2 (стойност 3): ляво дете = 2*2+1 = 5 → [9] ✓
                        дясно дете = 2*2+2 = 6 → извън масива (няма)
```

## Вмъкване - insert (sift-up)

**Идея:**
1. Добави новия елемент в **края** на масива (следващата свободна позиция)
2. "Изкачвай" го нагоре, докато е по-малък от родителя си (sift-up / bubble-up)

```cpp
void push(int value) {
    data.push_back(value);
    int i = data.size() - 1;

    while (i > 0) {
        int parent = (i - 1) / 2;
        if (data[parent] <= data[i]) break;  // heap свойство спазено
        swap(data[i], data[parent]);
        i = parent;
    }
}
```

## Insert - визуализация

```
Начало:  [2, 5, 3, 8, 7, 9]     insert(1)

Стъпка 1: добавяме в края
[2, 5, 3, 8, 7, 9, 1]
                  idx6, родител idx2=3 → 1<3, размяна

Стъпка 2:
[2, 5, 1, 8, 7, 9, 3]
            idx2, родител idx0=2 → 1<2, размяна

Стъпка 3 (край - idx0 няма родител):
[1, 5, 2, 8, 7, 9, 3]

Резултат като дърво:
          [1]
        /     \
      [5]     [2]
      / \      / \
    [8] [7] [9] [3]
```

## Изваждане на минимума - extract_min (sift-down)

**Идея:**
1. Коренът (индекс 0) е минимумът - той е отговорът
2. Премести **последния** елемент на мястото на корена
3. Смали масива с 1
4. "Спускай" новия корен надолу, като разменяш с **по-малкото** дете (sift-down)

```cpp
int pop() {
    int min_val = data[0];
    data[0] = data.back();
    data.pop_back();

    int i = 0;
    int n = data.size();
    while (true) {
        int left = 2*i + 1, right = 2*i + 2, smallest = i;
        if (left  < n && data[left]  < data[smallest]) smallest = left;
        if (right < n && data[right] < data[smallest]) smallest = right;
        if (smallest == i) break;
        swap(data[i], data[smallest]);
        i = smallest;
    }
    return min_val;
}
```

---

## Extract_min - визуализация

```
Начало: [1, 5, 2, 8, 7, 9, 3]     pop()

Стъпка 1: вземи корена (1), премести последния (3) на негово място
[3, 5, 2, 8, 7, 9]

Стъпка 2: сравни idx0=3 с децата idx1=5, idx2=2 → по-малкото е idx2=2
3 > 2 → размяна
[2, 5, 3, 8, 7, 9]

Стъпка 3: idx2=3, дете idx5=9 (единствено) → 3 < 9, спри

Резултат: [2, 5, 3, 8, 7, 9]   (връщаме 1 като минимум)

Като дърво:
          [2]
         /   \
       [5]   [3]
       / \    /
     [8] [7] [9]
```

## Пълна имплементация на C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

class MinHeap {
private:
    vector<int> data;

    void sift_up(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (data[parent] <= data[i]) break;
            swap(data[i], data[parent]);
            i = parent;
        }
    }

    void sift_down(int i) {
        int n = data.size();
        while (true) {
            int left = 2*i + 1, right = 2*i + 2, smallest = i;
            if (left  < n && data[left]  < data[smallest]) smallest = left;
            if (right < n && data[right] < data[smallest]) smallest = right;
            if (smallest == i) break;
            swap(data[i], data[smallest]);
            i = smallest;
        }
    }
```

## Пълна имплементация - публичен интерфейс

```cpp
public:
    void push(int value) {
        data.push_back(value);
        sift_up(data.size() - 1);
    }

    int pop() {
        int min_val = data[0];
        data[0] = data.back();
        data.pop_back();
        if (!data.empty()) sift_down(0);
        return min_val;
    }

    int top() const { return data[0]; }
    bool empty() const { return data.empty(); }
    int size() const { return data.size(); }
};
```

## Build-heap - изграждане от готов масив

- Вместо `push` елемент по елемент (O(n log n)), можем да построим heap за **O(n)**
- Идея: приложи `sift_down` върху всички **вътрешни** върхове, като тръгнеш от **последния родител** назад до корена

```cpp
void build_heap(vector<int>& data) {
    int n = data.size();
    for (int i = n / 2 - 1; i >= 0; i--) {
        sift_down(data, i, n);
    }
}
```

- Листата (последната половина от масива) вече спазват heap свойството тривиално - обработваме само родителите

---

## Сложност на операциите

| Операция          | Сложност | Бележка                              |
| ------------------ | -------- | ------------------------------------- |
| `push` (insert)     | O(log n) | височината на дървото е log n         |
| `pop` (extract_min) | O(log n) | sift-down до листата                  |
| `top` (peek)        | O(1)     | коренът винаги е на индекс 0          |
| `build_heap`        | O(n)     | по-бързо от n пъти `push`             |
| Търсене на произволен елемент | O(n) | heap не е оптимизиран за търсене |

## `std::priority_queue` - готовата имплементация

- C++ предоставя `std::priority_queue` в `<queue>` - по подразбиране е **max-heap**

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    priority_queue<int> pq;   // max-heap по подразбиране

    pq.push(5);
    pq.push(1);
    pq.push(9);
    pq.push(3);

    while (!pq.empty()) {
        cout << pq.top() << " ";  // 9 5 3 1
        pq.pop();
    }
}
```

#include <vector>

## Custom компаратор

```cpp
struct Task {
    string name;
    int priority;
};

// по-малък приоритет = по-важна задача → искаме min-heap по priority
struct CompareTask {
    bool operator()(const Task& a, const Task& b) {
        return a.priority > b.priority;  // "по-голямо" означава "по-нисък приоритет" в heap-а
    }
};

priority_queue<Task, vector<Task>, CompareTask> tasks;
tasks.push({"Fix bug", 1});
tasks.push({"Write docs", 3});
tasks.push({"Server down!", 0});

cout << tasks.top().name;  // "Server down!" (най-нисък priority число)
```

## Основни методи на `std::priority_queue`

```cpp
priority_queue<int> pq;

pq.push(x);      // вмъкване - O(log n)
pq.pop();        // премахва връхния елемент - O(log n)
pq.top();        // достъп до връхния елемент - O(1)
pq.empty();      // проверка дали е празна
pq.size();       // брой елементи
```

> За разлика от `queue`/`stack`, `priority_queue` **няма** итератори - не може да обходиш елементите без да ги извадиш

## Приложения на heap

- **Приоритетна опашка** - обработка на задачи по приоритет (ОС планировчици, симулации)
- **Dijkstra** - намиране на най-къс път в претеглен граф (винаги обработваме най-близкия неразгледан връх)
- **Heap Sort** - сортиране чрез многократно extract_min/max - O(n log n)
- **Top-K елементи** - намиране на K-те най-големи/малки елемента от голям поток данни
- **Медиана в поток от данни** - два heap-а (min-heap + max-heap)

```
Top-3 най-големи от [4, 1, 9, 6, 3, 8, 2]:
  min-heap с размер 3 → пази винаги 3-те най-големи видени досега
  Резултат: 6, 8, 9
```

## Кога да използваме heap?

**Heap / `priority_queue`** - когато:
- Трябва многократно да вадиш **минимума/максимума**
- Не ти трябва пълна наредба, само връхния елемент
- Имплементираш алгоритъм с приоритети (Dijkstra, планиране на задачи)

**Не използвай heap**, когато:
- Трябва ти **сортиран** достъп до всички елементи (използвай `set`/`map`)
- Трябва ти търсене по произволна стойност (heap е O(n) за това)

## Обобщение

- **Heap** е пълно двоично дърво, което спазва heap свойство (min или max)
- Пази се компактно в **масив** - индексна аритметика вместо указатели
- `push` и `pop` са **O(log n)**, `top` е **O(1)**
- `build_heap` от готов масив е **O(n)**, по-бързо от вмъкване елемент по елемент
- `std::priority_queue` е готовата имплементация в C++ - по подразбиране max-heap
- Основно приложение: приоритетни опашки, Dijkstra, heap sort, top-K задачи
