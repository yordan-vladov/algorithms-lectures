## Мотивация

- LinkedList търси в O(n) — твърде бавно при много данни
- HashMap е O(1) средно, но не пази **наредба** на ключовете
- Трябват ни структури, които съчетават **бързо търсене** и **наредба**

```
Проблем: намери всички студенти с оценка между 5 и 6
  HashMap → трябва да обходим всичко: O(n)
  BST     → намираме границата и обхождаме: O(log n + k)
```

## Основни понятия - Дърво

```
          [8]          ← корен (root)
         /   \
       [3]   [10]      ← вътрешни върхове (internal nodes)
       / \      \
     [1] [6]   [14]   ← листа (leaves)
         / \
       [4] [7]

Родител на [6] → [3]
Деца на [3]    → [1], [6]
Дълбочина на [6] → 2 (брой ребра от корена)
Височина на дървото → 3
```

- **Корен (root)** — върхът без родител
- **Лист (leaf)** — връх без деца
- **Поддърво (subtree)** — всеки връх заедно с децата му

## Двоично дърво за търсене (BST)

**Свойство на BST:** за всеки връх V:
- Всички стойности в **лявото** поддърво са **по-малки** от V
- Всички стойности в **дясното** поддърво са **по-големи** от V

```
          [8]
         /   \
       [3]   [10]
       / \      \
     [1] [6]   [14]
         / \
       [4] [7]

Проверка: [6] → ляво [4] < 6 ✓,  дясно [7] > 6 ✓
          [3] → всичко вляво < 3 ✓, всичко вдясно > 3 ✓
```

---

## Имплементация на BST - структура

```cpp
#include <iostream>
using namespace std;

struct Node {
    int value;
    Node* left;
    Node* right;

    Node(int v) : value(v), left(nullptr), right(nullptr) {}
};

class BST {
private:
    Node* root;

    Node* insert(Node* node, int value) {
        if (!node) return new Node(value);
        if (value < node->value)
            node->left = insert(node->left, value);
        else if (value > node->value)
            node->right = insert(node->right, value);
        return node;
    }
```

---

## Имплементация на BST - търсене

```cpp
    bool search(Node* node, int value) const {
        if (!node) return false;
        if (value == node->value) return true;
        if (value < node->value)
            return search(node->left, value);
        return search(node->right, value);
    }

public:
    BST() : root(nullptr) {}

    void insert(int value) { root = insert(root, value); }
    bool search(int value) const { return search(root, value); }
};
```

- Всяка стъпка **намалява наполовина** пространството за търсене → O(log n) средно

## Визуализация - search() стъпка по стъпка

```
Търсим 4 в дървото:

         [8]         сравни: 4 < 8  → върви наляво
        /   \
      [3]  [10]      сравни: 4 > 3  → върви надясно
      / \      \
    [1] [6]   [14]   сравни: 4 < 6  → върви наляво
        / \
      [4] [7]        сравни: 4 == 4 → НАМЕРЕН ✓

Пътят: 8 → 3 → 6 → 4   (3 сравнения вместо 7 при линейно търсене)
```

```
Търсим 5 в дървото:

         [8]         сравни: 5 < 8  → наляво
        /   \
      [3]  [10]      сравни: 5 > 3  → надясно
      / \      \
    [1] [6]   [14]   сравни: 5 < 6  → наляво
        / \
      [4] [7]        сравни: 5 > 4  → надясно → nullptr

Пътят: 8 → 3 → 6 → 4 → null   → НЕ Е НАМЕРЕН ✗
```

## Основни операции на BST

| Операция     | Средно   | Най-лошо | Бележка                              |
| ------------ | -------- | -------- | ------------------------------------ |
| `insert(x)`  | O(log n) | O(n)     | O(n) при сортиран вход (изродено дърво) |
| `search(x)`  | O(log n) | O(n)     |                                      |
| `remove(x)`  | O(log n) | O(n)     |                                      |
| Памет        | O(n)     | O(n)     |                                      |

- "Изродено дърво" = вмъкваме 1, 2, 3, 4... → дървото се превръща в свързан списък

## Обхождания на дърво

Три основни обхождания **в дълбочина (DFS)**:

```
          [8]
         /   \
       [3]   [10]
       / \      \
     [1] [6]   [14]

Inorder   (ляво → корен → дясно): 1  3  6  8  10  14  ← сортиран ред!
Preorder  (корен → ляво → дясно): 8  3  1  6  10  14
Postorder (ляво → дясно → корен): 1  6  3  14  10  8
```

- **Inorder** на BST винаги дава **сортирана** последователност

---

## Имплементация на обхожданията

```cpp
void inorder(Node* node) {
    if (!node) return;
    inorder(node->left);
    cout << node->value << " ";
    inorder(node->right);
}

void preorder(Node* node) {
    if (!node) return;
    cout << node->value << " ";
    preorder(node->left);
    preorder(node->right);
}

void postorder(Node* node) {
    if (!node) return;
    postorder(node->left);
    postorder(node->right);
    cout << node->value << " ";
}
```

## Обхождане в ширина (BFS) на дърво

```
          [8]           Ниво 0
         /   \
       [3]   [10]       Ниво 1
       / \      \
     [1] [6]   [14]    Ниво 2

BFS ред: 8  3  10  1  6  14
```

```cpp
#include <queue>

void bfs(Node* root) {
    if (!root) return;
    queue<Node*> q;
    q.push(root);
    while (!q.empty()) {
        Node* curr = q.front(); q.pop();
        cout << curr->value << " ";
        if (curr->left)  q.push(curr->left);
        if (curr->right) q.push(curr->right);
    }
}
```

- Използваме `queue` — обхождаме ниво по ниво

## Приложения на обхожданията

| Обхождане    | Приложение                                       | Пример                                      |
| ------------ | ------------------------------------------------ | ------------------------------------------- |
| **Inorder**  | Отпечатване на BST в сортиран ред                | Извличане на всички ключове наредени        |
| **Inorder**  | Валидация дали дърво е BST                       | Проверяваме дали inorder е строго нарастващ |
| **Preorder** | Копиране / сериализация на дърво                 | Запазване на дърво във файл                 |
| **Preorder** | Генериране на prefix изрази                      | `+ * 2 3 4` от аритметично дърво           |
| **Postorder**| Изтриване на дърво (деца преди родител)          | `delete` без dangling pointers              |
| **Postorder**| Изчисляване на аритметични изрази                | `2 3 * 4 +` = 10                            |
| **BFS**      | Намиране на най-краткия път (брой ребра)         | Най-малко стъпки от корен до листо          |
| **BFS**      | Обхождане ниво по ниво (напр. печат на дървото) | Визуализация по нива                        |

## Пример - Postorder за изчисляване на израз

```
Аритметично дърво за: (2 * 3) + 4

        [+]
       /   \
     [*]   [4]
     / \
   [2] [3]

Postorder: 2  3  *  4  +

Изпълнение (стек):
  push 2       → [2]
  push 3       → [2, 3]
  *: pop 3, 2  → push 6        → [6]
  push 4       → [6, 4]
  +: pop 4, 6  → push 10       → [10]
  Резултат: 10 ✓
```

## Пример - BFS за намиране на най-плитък лист

```
          [8]          ← ниво 0
         /   \
       [3]   [10]      ← ниво 1
       / \      \
     [1] [6]   [14]   ← ниво 2
         / \
       [4] [7]         ← ниво 3

BFS спира при първия лист: [1] на ниво 2
DFS (inorder) ще стигне до [1] също, но не гарантира "най-плитък"
```

- BFS е правилният избор когато търсим **минимална дълбочина** или **брой стъпки**

## `std::map` - стандартното BST в C++

- C++ предоставя `std::map` в `<map>` — имплементирано като **червено-черно дърво**
- Гарантира O(log n) за всички операции (не O(n) при небалансирано дърво)
- Ключовете са **автоматично сортирани**

```cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<string, int> grades;

    grades["Alice"] = 6;
    grades["Bob"]   = 5;
    grades["Carol"] = 4;

    // Итерация → по азбучен ред на ключовете
    for (auto& [name, grade] : grades)
        cout << name << ": " << grade << "\n";
    // Изход: Alice: 6, Bob: 5, Carol: 4  (сортирано)
}
```

---

## Основни методи на `std::map`

```cpp
map<string, int> m;

m["key"] = value;          // вмъкване / обновяване
m.insert({"key", value});  // вмъкване (не презаписва)
m.erase("key");            // изтриване
m.count("key");            // 1 ако ключът съществува, 0 иначе
m.find("key");             // итератор (m.end() ако не е намерен)
m.size();                  // брой двойки

// Обхождане в сортиран ред:
for (auto& [k, v] : m)
    cout << k << " → " << v << "\n";
```

> **Разлика с `unordered_map`:** `map` е O(log n) но **сортиран**; `unordered_map` е O(1) средно но **несортиран**

## Кога да използваме BST / `std::map`?

**BST (`std::map`)** — когато:
- Трябва **сортиран** достъп до ключовете
- Нужни са **range queries**: всички ключове между A и B
- Честите операции са insert/delete/search с гарантирано O(log n)

**`unordered_map`** — когато:
- Не ни трябва наредба
- Искаме максимална скорост: O(1) средно

## Обобщение

- **BST** пази наредба и дава O(log n) за insert/search/delete (средно)
- Три DFS обхождания: **inorder** (сортиран ред), **preorder**, **postorder**
- **BFS** обхожда ниво по ниво с `queue`
- "Изродено дърво" при сортиран вход → O(n) сложност
- `std::map` е готовото BST в C++ — гарантира O(log n) и сортиран ред
