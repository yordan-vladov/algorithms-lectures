# Графи - Обхождане в дълбочина (DFS)

---

## Какво ще научим днес?

- Кратко повторение: представяне на граф
- Идеята зад обхождане в дълбочина (DFS)
- Имплементация на DFS - рекурсивна и итеративна
- Приложения на DFS: откриване на цикли, топологично сортиране
- Сложност на DFS

---

## Повторение - списък на съседство

```cpp
#include <vector>
const int N = 4;
vector<int> adj[N];

void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u);  // за ненасочен граф
}
```

- В тази лекция обхождаме граф, представен като списък на съседство

---

## Обхождане на граф в дълбочина (DFS)

```
Граф:  0—1, 0—2, 1—3, 2—3
DFS от 0: 0 → 1 → 3 → 2

  посети 0 → посети съсед 1 → посети съсед 3
           → 3 няма непосетени съседи, върни се
           → посети съсед 2 (от 0)
```

- DFS навлиза **колкото е възможно по-дълбоко**, преди да се върне назад (backtrack)

---

## Имплементация на DFS

```cpp
void dfs(int u, vector<int> adj[], vector<bool>& visited) {
    visited[u] = true;
    cout << u << " ";
    for (int v : adj[u])
        if (!visited[v])
            dfs(v, adj, visited);
}

// Извикване:
vector<bool> visited(n, false);
dfs(0, adj, visited);
```

---

## Визуализация - стек на извикванията

```
Граф:  0—1, 0—2, 1—3, 2—3

Извикване:              Стек на извикванията:
dfs(0)                  [dfs(0)]
  dfs(1) (съсед на 0)   [dfs(0), dfs(1)]
    dfs(3) (съсед на 1) [dfs(0), dfs(1), dfs(3)]
      съседи на 3: 1(посетен), 2(непосетен)
    dfs(2) (съсед на 3) [dfs(0), dfs(1), dfs(3), dfs(2)]
      съседи на 2: 0(посетен), 3(посетен) → връщане
    връщане от dfs(3)
  връщане от dfs(1)
връщане от dfs(0)

Ред на посещение: 0 → 1 → 3 → 2
```

## DFS с явен стек (без рекурсия)

```cpp
#include <stack>

void dfsIterative(int start, vector<int> adj[], int n) {
    vector<bool> visited(n, false);
    stack<int> s;
    s.push(start);
    while (!s.empty()) {
        int u = s.top(); s.pop();
        if (visited[u]) continue;
        visited[u] = true;
        cout << u << " ";
        for (int v : adj[u])
            if (!visited[v])
                s.push(v);
    }
}
```

- Рекурсията всъщност използва **системния стек** — итеративната версия го прави явно със `stack`

## Приложение - откриване на цикъл с DFS

```cpp
bool hasCycle(int u, int parent, vector<int> adj[], vector<bool>& visited) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (!visited[v]) {
            if (hasCycle(v, u, adj, visited)) return true;
        } else if (v != parent) {
            return true;  // посетен съсед, който не е родителят → цикъл
        }
    }
    return false;
}
```

- Ако срещнем вече посетен връх, който **не е родителят** ни → намерили сме цикъл

## Приложение - топологично сортиране

- Топологично сортиране подрежда върховете на **насочен ацикличен граф (DAG)** така, че за всяко ребро u→v, u идва преди v
- Използва се при зависимости между пакети (npm, apt) и планиране на задачи

```
Зависимости:  compile → link → run
              (compile трябва да е преди link, link преди run)

DFS идея: добави връх в резултата едва след като всичките му съседи
          са напълно обходени (postorder), после обърни реда
```

## Сложност на DFS

| Ресурс         | Сложност | Бележка                                    |
| -------------- | -------- | ------------------------------------------- |
| Време          | O(V + E) | Всеки връх и ребро се разглеждат веднъж    |
| Памет          | O(V)     | `visited[]` + стек на извикванията (в най-лошия случай O(V) дълбочина) |

## Обобщение

- DFS навлиза максимално дълбоко, преди да се върне назад (backtrack)
- Имплементира се лесно с рекурсия или с явен `stack`
- O(V + E) по време, O(V) по памет за `visited[]` и стека на извикванията
- Открива цикли и се използва за топологично сортиране на DAG
- В следващата лекция: **BFS** — обхождане ниво по ниво
