## Повторение - списък на съседство

```cpp
#include <vector>
const int N = 4;
vector<int> adj[N];

void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u);  // за ненасочен граф
}
```

- В тази лекция обхождаме граф, представен като списък на съседство

---

## Обхождане на граф в ширина (BFS)

```
Граф:  0—1, 0—2, 1—3, 2—3
BFS от 0: 0 → 1, 2 → 3

  стъпка 1: обработи 0, добави съседи 1, 2  →  queue: [1, 2]
  стъпка 2: обработи 1, добави съсед 3       →  queue: [2, 3]
  стъпка 3: обработи 2, 3 вече е в опашката →  queue: [3]
  стъпка 4: обработи 3                       →  queue: []
```

- BFS обхожда **ниво по ниво**, използвайки `queue`

## Имплементация на BFS

```cpp
#include <queue>
#include <vector>

void bfs(int start, int n, vector<int> adj[]) {
    vector<bool> visited(n, false);
    queue<int> q;
    visited[start] = true;
    q.push(start);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << u << " ";
        for (int v : adj[u])
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
    }
}
```

---

## Визуализация - обхождане по нива

```
Граф:  0—1, 0—2, 1—3, 2—3
BFS от 0:

Ниво 0: {0}
Ниво 1: {1, 2}   ← директни съседи на 0
Ниво 2: {3}      ← съсед на 1 и 2, вече не се добавя повторно

Ред на посещение: 0 → 1 → 2 → 3
```

## BFS за намиране на най-кратък път

```cpp
#include <algorithm>

vector<int> shortestPath(int start, int end, int n, vector<int> adj[]) {
    vector<int> dist(n, -1), parent(n, -1);
    queue<int> q;
    dist[start] = 0;
    q.push(start);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u])
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                parent[v] = u;
                q.push(v);
            }
    }
    if (dist[end] == -1) return {};  // няма път

    vector<int> path;
    for (int at = end; at != -1; at = parent[at])
        path.push_back(at);
    reverse(path.begin(), path.end());
    return path;
}
```

- `dist[v]` = най-малкият брой ребра от `start` до `v` (непретеглен граф)
- `parent[]` позволява да **реконструираме** пътя, връщайки се назад от `end`

## Приложение - навигация

```
Карта на градове като граф:
  [Sofia] —3h— [Plovdiv] —1h— [Burgas]
     \                          /
      ——————————4h—————————————

BFS (по брой спирки): Sofia → Plovdiv → Burgas  (2 ребра = по-малко спирки)
```

- BFS намира пътя с **най-малко ребра** (спирки), не непременно най-краткия по време/разстояние — за претеглени графи се използва Dijkstra

---

## BFS срещу DFS за графи

| Характеристика          | BFS                          | DFS                          |
| ------------------------ | ----------------------------- | ----------------------------- |
| Структура                | `queue`                       | Рекурсия / `stack`            |
| Обхождане                | Ниво по ниво                  | Колкото е възможно навътре    |
| Намиране на кратък път   | ✓ (при единично тегло)        | ✗                             |
| Намиране на цикли        | ✓                              | ✓                              |
| Топологично сортиране    | ✗                              | ✓                              |
| Сложност                 | O(V + E)                      | O(V + E)                      |

---

## Реални приложения на графи

- **Навигация** — градовете са върхове, пътищата са ребра (BFS/Dijkstra)
- **Социални мрежи** — "приятели на приятели" на разстояние K се намират с BFS
- **Интернет маршрутизация** — намиране на маршрут с най-малко хопове
- **Web crawling** — обхождане на страници ниво по ниво от начална страница

## Обобщение

- **BFS** обхожда ниво по ниво с `queue` — намира най-краткия път в непретеглен граф
- `dist[]` и `parent[]` позволяват намиране на дължината и реконструкция на пътя
- BFS и DFS имат еднаква времева сложност O(V + E), но различна стратегия и приложения
- **BFS** → най-къси пътища; **DFS** → цикли, топологично сортиране
- Графите моделират навигация, социални мрежи, зависимости и маршрутизация в реалния свят
