## Мотивация

- Представете си, че подреждате карти за игра в ръката си
- Взимате карта по карта и я вмъквате на правилното място сред вече подредените
- Точно това прави **Insertion Sort**

```
Ръка: [подредени карти]  +  [нова карта] → вмъкни на правилното място
```

---

## Какво е Insertion Sort?

- **Insertion Sort** разделя масива на две части:
  - **Сортирана** част (в началото, първоначално само първият елемент)
  - **Несортирана** част (остатъкът)
- На всяка стъпка:
  1. Взима **първия** елемент от несортираната част (`key`)
  2. Премества го назад в сортираната част, докато намери правилното му място

---

## Принцип на работа - визуализация

```
[10, 7, 8, 9, 1, 5]
 └┘  └──── несортирана ────┘
 сортирана (само 10)

key = 7:  7 < 10 → премести 10 надясно  → [7, 10, 8, 9, 1, 5]
                                             └───┘
key = 8:  8 < 10, 8 > 7 → вмъкни между 7 и 10
                                            → [7, 8, 10, 9, 1, 5]
```

---

## Принцип на работа - продължение

```
key = 9:  9 < 10, 9 > 8 → вмъкни между 8 и 10
                                            → [7, 8, 9, 10, 1, 5]

key = 1:  по-малък от всички → премести всички надясно
                                            → [1, 7, 8, 9, 10, 5]

key = 5:  5 < 10,9,8,7, 5 > 1 → вмъкни след 1
                                            → [1, 5, 7, 8, 9, 10]  ← сортиран!
```

---

## Псевдокод

```
за i от 1 до n - 1:
    key = arr[i]
    j = i - 1

    // местим елементите, по-големи от key, надясно
    докато j >= 0 и arr[j] > key:
        arr[j + 1] = arr[j]
        j = j - 1

    arr[j + 1] = key
```

- Не разменя елементи като Bubble/Selection Sort - **измества** ги и вмъква `key` веднъж

---

## Примерна имплементация на C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

void insertionSort(vector<int>& arr) {
    int n = arr.size();

    for (int i = 1; i < n; i++) {
        int key = arr[i];   // елементът, който вмъкваме
        int j = i - 1;

        // местим елементите, по-големи от key, надясно
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;   // вмъкваме key на освободеното място
    }
}
```

*(пълният код е във `insertion_sort.cpp`)*

## Пример за употреба

```cpp
int main() {
    vector<int> arr = {10, 7, 8, 9, 1, 5};

    insertionSort(arr);

    for (int x : arr) cout << x << " ";
    // Изход: 1 5 7 8 9 10
}
```

## Сложност във времето

| Случай     | Сложност | Кога се случва                              |
| ---------- | -------- | --------------------------------------------- |
| Най-добър  | O(n)     | Масивът вече е сортиран - вътрешният цикъл спира веднага |
| Среден     | O(n²)    | Случайно наредени елементи                    |
| Най-лош    | O(n²)    | Масивът е сортиран в обратен ред               |

- Много ефективен при **почти сортирани** данни

---

## Сложност по памет

- Сортира **на място** (in-place)
- Памет: **O(1)**

---

## Предимства на Insertion Sort

- **Много ефективен** при малки или почти сортирани масиви - O(n) в най-добрия случай
- **Стабилен** - елементи с еднакви стойности запазват реда си
- **In-place** - памет O(1)
- **Онлайн алгоритъм** - може да сортира данни, докато пристигат (не е нужен целият масив предварително)

---

## Недостатъци на Insertion Sort

- **Бавен** при големи, случайно наредени масиви - O(n²)
- Много измествания при масив, сортиран в обратен ред

---

## Insertion Sort срещу Bubble Sort и Selection Sort

| Характеристика      | Insertion Sort         | Selection Sort  | Bubble Sort            |
| -------------------- | ------------------------ | ---------------- | ------------------------ |
| Най-добър случай     | O(n)                     | O(n²)            | O(n) (с оптимизация)     |
| Стабилност           | Да                       | Не               | Да                       |
| Онлайн (streaming)   | Да                       | Не               | Не                       |
| Практическа скорост  | Най-бърз от трите         | Среден           | Най-бавен                |

---

## Кога да използваме Insertion Sort?

- При **малки** масиви (n < ~10-20) - дори бързите алгоритми преминават към него
- При **почти сортирани** данни
- При **онлайн сортиране** - когато данните пристигат постепенно (напр. поток от събития)
- Използва се като "долна граница" в хибридни алгоритми - напр. Timsort, Introsort

## Обобщение

- Insertion Sort изгражда сортираната част елемент по елемент, вмъквайки всеки на правилното място
- Сложност **O(n)** в най-добрия случай, **O(n²)** в среден/най-лош
- Стабилен, in-place, онлайн - много ефективен за малки или почти сортирани данни
